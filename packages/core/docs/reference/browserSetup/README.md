# Browser setup

Render a browser, create its stores, and access them from hosted components.

- [GenomeBrowser](GenomeBrowser.md): Render a responsive or fixed-width browser and magnify its SVG.
- [Browser store](browserStore.md): Initialize and change viewport state, selection, and highlights.
- [Track store](trackStore.md): Register modules and add, update, remove, order, or pin tracks.
- [useGenomeBrowser](useGenomeBrowser.md): Resolve the hosting browser's stores from renderers, settings, and tooltips.

See the [complete export index](../README.md#public-export-index) to look up a symbol by name.
