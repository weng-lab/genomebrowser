# Collections and schemas

Define track collections, validate their input, generate JSON schemas for editors, and validate saved browser state.

- [validateTrackCollection](validateTrackCollection.md): Validate collection input against the registered track modules.
- [generateTrackCollectionJsonSchema](generateTrackCollectionJsonSchema.md): Generate a collection input schema in JavaScript.
- [Schema CLI](schemaCli.md): Write and check generated schema files from the command line.
- [Track collections](trackCollection.md): Define track entries, metadata, views, and columns.
- [State schemas](stateSchemas.md): Validate browser settings, highlights, and track bases with the browser's own Zod schemas.

See the [complete export index](../README.md#public-export-index) to look up a symbol by name.
