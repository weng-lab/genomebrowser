# Renderer integration

Draw track data and connect SVG content to interactions, tooltips, and automatic sizing.

- [Track renderers](trackRenderer.md): Draw SVG content using the supplied data and coordinates.
- [useBasePairDetail](useBasePairDetail.md): Share the browser's nucleotide-detail decision, with status and a zoom target for controls.
- [useInteraction](useInteraction.md): Call application handlers when a feature is clicked or hovered.
- [useTooltip](useTooltip.md): Show and hide a module's SVG tooltip for an item.
- [useAutoTrackHeight](useAutoTrackHeight.md): Derive track height from rendered row count.
- [TrackOverlay](TrackOverlay.md): Place fixed SVG content over the visible plot.
- [TrackLabel](TrackLabel.md): Place styled text at a plot edge or corner.

See the [complete export index](../README.md#public-export-index) to look up a symbol by name.
