# Getting started

Build one React integration through these chapters, in order.

- [Create a genome browser](01-firstBrowser.md): choose a setup path and connect the assembly, stores, and first tracks.
- [Add and configure tracks](02-configureTracks.md): configure tracks, ordering, settings, and feature clicks.
- [Navigate and select regions](03-navigationAndSelection.md): pan, zoom, mark regions, and add controls.
- [Use track collections](04-trackCollections.md): define collections, load tracks, and offer selection.
