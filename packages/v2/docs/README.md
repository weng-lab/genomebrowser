# @weng-lab/genomebrowser-v2 Docs

These docs are for users of `@weng-lab/genomebrowser-v2`.

They are intended to ship with the npm package and be readable from `node_modules/@weng-lab/genomebrowser-v2/docs`.

Keep package docs self-contained. Do not link to files in the repository root `docs/` folder, because those links will not work from an installed package.

Detailed user documentation is intentionally scaffolded here and will be filled in as the v2 package docs are written.
