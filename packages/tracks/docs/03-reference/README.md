# Tracks API reference

Import individual modules from `@weng-lab/genomebrowser-tracks/<track>`, shared utilities from `@weng-lab/genomebrowser-tracks/shared`, and `firstPartyTrackModules` from the package root. The folders below organize documentation; they are not additional import paths. Internal source files are not public package entries.

## Browse by area

- [Track modules](01-trackModules/README.md): one self-contained page per module, including configuration, displays, data, interactions, and module-specific helpers.
- [Collections and schemas](02-collectionsAndSchemas/README.md): the complete registry and bundled JSON schema.
- [BED schemas and signal processing](03-dataPrimitives/README.md): BED parsing presets and signal condensation.
- [Coordinates and layout](04-coordinatesAndLayout/README.md): coordinate conversion, row packing, and sizing.
- [Settings components](05-settingsComponents/README.md): form layout, base settings, dimensions, and editable fields.
- [Tooltips](06-tooltips/README.md): SVG content and display formatting.
