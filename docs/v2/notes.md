## Ideas

An npm cli that accepts a json input to set internal tracks in a local browser Next or SPA app

gb.config.ts serves as the entry point for the track modules, and the json schema to be able to seed the SPA with data. The SPA will be a stripped down version of the production website, which will include a full UI/UX suite of tools and whatnot. Connections like accounts etc. This will be the most powerful version, but the SPA must also do a lot and be adjustable. It is open source so users can clone the repo and adjust the SPA themselves if they want.
