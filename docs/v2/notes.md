# Archived v2 Notes

This page is retained only as a record of early documentation and application ideas. It is not current design guidance or an implementation plan.

For current maintainer guidance, use [v2 Concepts](concepts.md), [Tracks and track modules](tracks.md), and the accepted documents under `adr/`. User-facing package documentation lives under `packages/v2/docs`.

Earlier ideas included generating a local browser application from JSON and using a `gb.config.ts` entry point for modules and schemas. Those ideas are not part of the current documented package contract.
