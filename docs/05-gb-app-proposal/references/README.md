# Earlier design notes

These notes are an earlier attempt to think through the app in detail. They are closer to a working brain dump than an agreed specification. Everything here is open for debate, including records labeled "Decided" and statements written as rules.

Start with the [current proposal](../README.md). Use these references when a topic needs more detail or when it helps to see an approach that was considered. They are not additional requirements for the January release, and some conflict with the current proposal. For example, these notes discuss Better Auth; the current proposal uses Clerk.

If an idea here is useful, discuss it and add the agreed version to the main proposal. There is no need to implement the whole reference set or keep every old suggestion current.
